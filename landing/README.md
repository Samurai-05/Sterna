# Sterna landing page

The public landing page for Sterna, an app that helps people save discoveries, reveal visited countries, and build shared travel maps.

## Development

From this directory:

```bash
npm install
npm run dev
```

The site is served at [http://localhost:3000](http://localhost:3000).

## Structure

- `src/components` contains the Sterna landing sections.
- `src/data/siteDetails.ts` holds the site metadata.
- `public/images/mockups/weekend-paris-phone.svg` is the mobile-app mockup used on the page.
