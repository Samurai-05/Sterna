# Local dependency patches

`@base-ui/react` 1.7.0 is currently the latest stable release. The Drawer
snap-point swipe fix from upstream issue [#5471](https://github.com/mui/base-ui/issues/5471)
and pull request [#5477](https://github.com/mui/base-ui/pull/5477) is applied in
`@base-ui+react+1.7.0.patch` for both distributed ESM and CommonJS builds.

Remove this patch when a stable `@base-ui/react` release containing #5477 is
available.
