# Documentation

Project documentation is grouped by subject:

- [Product](product/): project description and functional and non-functional requirements.
- [Architecture](architecture/): frontend and system architecture documentation.
- [Infrastructure](infrastructure/): setup and operational conventions for the services in `infra/`.
- [Decisions](decisions/): architecture decision records.
- [Design](design/): landing page and visual design documentation.
- [Process](process/): planning and working agreements.

The contribution guide is kept at the [repository root](../CONTRIBUTING.md).
